# 🧠 Simple Quiz App

A clean, interactive, and dark-themed multiple-choice quiz application built to test core knowledge across various topics while practicing state handling and dynamic UI updates.

## 🚀 Features

* **Dynamic Question Loading:** Renders multiple-choice questions cleanly within a dedicated quiz card.
* **Interactive Option Selection:** Clickable response buttons with hover states for intuitive navigation.
* **Modern Dark Theme:** Minimalist UI with high visual contrast designed to reduce eye strain.
* **Responsive Card Layout:** Adaptive container centered perfectly on desktop and mobile screens.

## 🔮 Upcoming Features

* **Score Tracker & Summary:** Display a final results screen with a total score breakdown upon completion.
* **Timer Component:** Add a countdown timer per question to gamify the user experience.
* **Progress Bar:** Show a visual indicator tracking how many questions are remaining.
* **Dynamic Feedback:** Highlight selected options immediately with correct (green) or incorrect (red) color states.

## 🛠️ Tech Stack

* **HTML5:** Structured semantic markup for the card element, header, and button group.
* **CSS3:** Flexbox centering, customized option buttons, and consistent dark mode styling.
* **JavaScript (ES6):** Object-based question array data structures and dynamic DOM rewriting logic.

## 💻 Getting Started

Follow these quick steps to get a local copy up and running on your machine.

### Prerequisites
You only need a modern web browser (like Chrome, Firefox, Safari, or Edge) to play the quiz.

### Installation & Setup
1. **Clone the repository**:
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory**:
   ```bash
   cd quiz-app
   ```
3. **Launch the application**:
   Simply open the `index.html` file directly in your browser.
