# 🛒 Simple E-Commerce Cart

A minimalist, interactive e-commerce product list and shopping cart application built to practice dynamic DOM state management and frontend UI development.

## 🚀 Features

* **Product Catalog:** Lists available products with clear, structured pricing displays.
* **Interactive Cart:** Add items to a dynamic shopping cart state seamlessly.
* **Modern Dark Theme:** High-contrast dark mode design with sleek violet interactive elements.
* **Responsive Layout:** Adaptive card design optimized for multiple screen dimensions.

## 🔮 Upcoming Features

* **Cart Summary:** Calculate total item count and final checkout subtotal pricing automatically.
* **Quantity Selectors:** Increment or decrement specific product counts directly inside the cart.
* **Remove Items:** Delete single selections or completely clear the current shopping cart state.
* **Local Storage Integration:** Persist cart selections securely across page refreshes.

## 🛠️ Tech Stack

* **HTML5:** Semantic architecture for layout sections.
* **CSS3:** Flexbox structure, custom styling variables, and cohesive dark theme colors.
* **JavaScript (ES6):** Dynamic array manipulation, state handling, and interactive click event listeners.

## 💻 Getting Started

Follow these quick steps to get a local copy up and running on your machine.

### Prerequisites
You only need a modern web browser (like Chrome, Firefox, Safari, or Edge) to test this project.

### Installation & Setup
1. **Clone the repository**:
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory**:
   ```bash
   cd simple-cart
   ```
3. **Launch the application**:
   Simply open the `index.html` file directly in your browser.
