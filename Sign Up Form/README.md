# 🔐 Simple Sign-Up Form

A clean, modern registration interface designed to capture user credentials with a strong emphasis on sleek typography and deep-shadow visual styling.

## 🚀 Features

* **Structured Form Inputs:** User-friendly placeholder fields for Name, Email, and Password.
* **Neumorphic Accent Shadows:** Distinct drop-shadow styling on input boxes and buttons for a tactile UI feel.
* **Cohesive Aesthetic:** Uniform violet and white color palette creating high visual contrast.
* **Responsive Card Layout:** Adaptive form module centered seamlessly for desktop and mobile layouts.

## ⚠️ Important Note

> 🛠️ **Current Status:** This project is currently in its frontend design phase. **JavaScript functionality will be added soon**, at which point form validation will become live and the **"Login Here!"** navigation feature will start working.

## 🔮 Upcoming Features

* **Form Validation:** Client-side email format validation and password strength checking via JavaScript.
* **Login Redirection:** Activating the toggle link to switch views dynamically between Sign-Up and Login forms.
* **Success Notifications:** Floating toast alerts indicating successful user registration submission.
* **Database Integration:** Connecting input states to a authentication backend or Local Storage mock service.

## 🛠️ Tech Stack

* **HTML5:** Semantic architecture utilizing appropriate form elements and input types.
* **CSS3:** Box-shadow styling mechanics, custom color variables, and Flexbox centering.

## 💻 Getting Started

Follow these quick steps to get a local copy up and running on your machine.

### Prerequisites
You only need a modern web browser (like Chrome, Firefox, Safari, or Edge) to view the layout.

### Installation & Setup
1. **Clone the repository**:
   ```bash
   git clone github.com
   ```
2. **Navigate into the directory**:
   ```bash
   cd signup-form
   ```
3. **Launch the application**:
   Simply open the `index.html` file directly in your web browser.
