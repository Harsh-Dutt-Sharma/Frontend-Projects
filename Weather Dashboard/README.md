# 🌤️ Multi-City Weather Dashboard

A sleek, dark-themed weather monitoring interface designed to let users bookmark multiple locations, manage a personalized watchlist, and view real-time meteorological conditions for selected cities.

## 🚀 Features

* **City Bookmark System:** Add custom cities to a dynamic saved locations list.
* **Persistent Watchlist:** View, track, and toggle between multiple locations seamlessly.
* **On-Demand Loading:** Click any saved city card to fetch and update its individual weather stats.
* **Modern Dark UI:** Clean, distraction-free aesthetic with high visual contrast purple action elements.

## 🔮 Upcoming Features

* **Dynamic Data Rendering:** Populate the 'Weather Info' area with detailed wind, humidity, and temperature data.
* **Remove Saved Locations:** Add a delete icon on each city row to remove it from the tracking list.
* **Local Storage Integration:** Persist your bookmarked cities array across page refreshes.
* **Error Handling:** Form validation alerts if a user inputs an empty or invalid city name.

## 🛠️ Tech Stack

* **HTML5:** Semantic construction for the input modules, lists, and information container.
* **CSS3:** Flexbox grid spacing, sleek form styling, and cohesive dark mode theme colors.
* **JavaScript (ES6):** State array tracking for saved cities and dynamic DOM event listener routing.

## 💻 Getting Started

Follow these quick steps to get a local copy up and running on your machine.

### Prerequisites
You only need a modern web browser and an active OpenWeatherMap API key (or similar provider).

### Installation & Setup
1. **Clone the repository**:
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory**:
   ```bash
   cd weather-dashboard
   ```
3. **Launch the application**:
   Simply open the `index.html` file directly in your browser.
