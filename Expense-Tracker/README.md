# 💰 Simple Expense Tracker

A sleek, dark-themed financial tracking application built to help users seamlessly record, monitor, and manage their daily expenses in one centralized dashboard.

## 🚀 Features

* **Log Expenses:** Add specific expense items with a designated name and numerical amount.
* **Remove Entries:** Instantly delete individual expense listings to keep records updated.
* **Live Calculation:** Dynamically updates the total spent amount on the dashboard.
* **Modern Dark Theme:** Features a high-contrast dark layout with clean purple action elements.

## 🔮 Upcoming Features

* **Category Filtering:** Tag entries under categories like Food, Utilities, or Entertainment.
* **Budget Allocator:** Set a monthly spending ceiling with visual alerts when limits approach.
* **Persistent Storage:** Integrate Local Storage to retain financial logs across page refreshes.
* **Data Visualization:** Implement charts to visually map out spending breakdowns over time.

## 🛠️ Tech Stack

* **HTML5:** Semantic skeleton for the input forms, lists, and summary fields.
* **CSS3:** Flexbox alignment, customized input fields, and cohesive dark mode colors.
* **JavaScript (ES6):** Dynamic array handling, state management, and continuous total math aggregation.

## 💻 Getting Started

Follow these quick steps to get a local copy up and running on your machine.

### Prerequisites
You only need a standard modern web browser (like Chrome, Firefox, or Edge) to launch this tool.

### Installation & Setup
1. **Clone the repository**:
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory**:
   ```bash
   cd expense-tracker
   ```
3. **Launch the application**:
   Simply open the `index.html` file directly in your browser.
