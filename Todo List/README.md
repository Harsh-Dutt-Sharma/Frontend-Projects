# 📝 Simple To-Do List

A minimalist, responsive web application built to help users seamlessly organize, track, and manage their daily tasks in one centralized place. 

## 🚀 Features

* **Add Tasks:** Create new todo items instantly.
* **Complete Tasks:** Toggle task completion status with a strike-through visual.
* **Delete Tasks:** Remove single items or clear the entire list.
* **Persistent Storage:** Saves data locally so tasks persist after refreshing the page.
* **Responsive Design:** Optimized for both mobile and desktop screens.

## 🔮 Upcoming Features

* **Priority Levels:** Assign high, medium, or low priority tags to urgent tasks.
* **Due Dates:** Add calendar deadlines and automatic visual alerts for overdue items.
* **Categories:** Group tasks into custom folders like Work, Personal, or Shopping.
* **Dark Mode:** Toggle between light and dark UI themes for better night viewing.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure.
* **CSS3:** Clean layout and modern styling.
* **JavaScript (ES6):** Dynamic DOM manipulation and Local Storage integration.

## 💻 Getting Started

Follow these quick steps to get a local copy up and running on your machine.

### Prerequisites
You only need a modern web browser (like Chrome, Firefox, or Edge) to run this project.

### Installation & Setup
1. **Clone the repository**:
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory**:
   ```bash
   cd todo-list
   ```
3. **Launch the application**:
   Simply open the `index.html` file directly in your browser, or use an extension like Live Server in VS Code.
